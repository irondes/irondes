# Irondes

Construo produtos e ferramentas com IA: agentes que trabalham com supervisão humana, memória compartilhada entre eles e um toolkit próprio de engenharia.

## No que estou construindo

- **Agentes de IA** que tocam tarefas do dia a dia, com aprovação humana nas decisões que importam.
- **Memória compartilhada** para vários agentes trabalharem com o mesmo contexto.
- **Ferramentas de engenharia com IA**, reaproveitadas em todos os meus projetos.

A maior parte desse trabalho ainda é privada. O que eu abrir vai para o Repo Livre.
